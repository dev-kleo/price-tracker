## 2.6.0
- Общая история цен (по желанию, выключена по умолчанию). Если включить, расширение отправляет на сервер проекта только три значения: магазин, ID товара и целую цену в рублях со страницы товара, которую вы открыли, не чаще одного раза в 6 часов на товар (или сразу при изменении цены). Без аккаунта, без адресов страниц, без личных данных. Не отправляются товары «Нет в наличии» и страницы, которые не удалось разобрать. Для Ozon и Яндекс Маркета отправляется цена без карты Ozon и без Яндекс Пэй.
- График товара объединяет вашу историю с общей (одна точка на каждую отметку времени, по возрастанию). Общая история кэшируется на 3 часа. Если точек меньше двух, график заменён пояснением: «История цены начнёт собираться с момента добавления. Первые данные — через 24 часа».
- Приветственная страница при первой установке из двух страниц (1 / 2): три шага с кнопкой «Далее», затем «История цены» с переключателем «Делиться ценами» (выключен по умолчанию, то же значение, что в Настройках), кнопки «Назад» и «Готово». «Пропустить» работает на обеих страницах. Показывается только при установке, не при обновлении.
- Пустой список теперь подсказывает, что делать, и показывает поддерживаемые магазины. Если активная вкладка не магазин, написано «Откройте товар на Ozon, Wildberries, Яндекс Маркете или AliExpress, чтобы начать отслеживание».
- Тот, кто уже пользуется расширением, один раз увидит вопрос про общую историю. Ответ «Не сейчас» оставляет её выключенной, включить можно в Настройках.
- Кнопка «EN» / «RU» в шапке: переключает язык всего интерфейса одним нажатием. Выбор сохраняется.
- Новые разрешения не нужны.

## 2.5.0
- Новый магазин: AliExpress Россия (aliexpress.ru). Доступ к сайту не запрашивается при обновлении: расширение продолжает работать как раньше, а разрешение браузер спросит только когда вы нажмёте «Включить AliExpress» (меню «⋯» или Настройки → Магазины). Скрипт для страниц подключается после выдачи доступа и восстанавливается после перезапуска браузера и обновления расширения. Доступ можно отозвать там же.
- Варианты товара (цвет, размер и т.д.): отслеживается цена выбранного варианта, каждый вариант хранится отдельным товаром со своей историей цен, на экране товара показана строка «Вариант». Если вариант определить нельзя, берётся цена товара целиком.
- Записывается только публичная цена со страницы. Цена с купоном продавца и персональные суммы не учитываются.
- Для AliExpress работают папки, график группы, переключатель «Показывать обычную цену», статус «Нет в наличии», экспорт и импорт данных.

## 2.4.0
- Небольшое окно «Нравится расширение?» на вкладке «Товары». Появляется не раньше чем через 7 дней после первого запуска, при 3+ товарах и реальной экономии за 30 дней. «Да» ведёт на страницу отзывов в Chrome Web Store, «Позже» прячет окно на 30 дней, любой ответ запоминается, и окно больше не показывается. Новые разрешения не нужны.

- Новый интерфейс: спокойный, точный и быстрый. Крупный заголовок «Товары», карточка «Сэкономили за 30 дней» (считается по сохранённой истории, скрыта при нулевой экономии), переключатель «Все / Снизились / Нет в наличии / Ошибки» со счётчиками, единый список с изображениями, плавающая панель вкладок «Товары / Папки / Уведомления».
- Экран товара: крупная цена, прежняя цена, «Вы экономите», «Максимум за 90 дней», плашка «Минимум за 60 дней» только когда это правда; график 30 / 90 / Всё с пунктирной линией минимума, маркером текущей цены и точным значением под курсором; «Уведомить, если ниже …» действительно задаёт целевую цену.
- График группы: поиск, «Найдено K из N», «Выбрать / Снять найденные», «Только найденные / Только выбранные», недоступные товары пунктиром, «На весь экран».
- Движение: пружинные переходы, которые можно прервать без рывков; свайп назад; шторки тянутся за пальцем и мышью; упругие края; «Отменить» после удаления действительно возвращает товар или папку вместе с историей.
- Тёмная тема по системе или вручную (Настройки → Оформление); поддержка «уменьшить движение», «уменьшить прозрачность» и «повышенная контрастность».
- Все цвета, размеры и тайминги вынесены в один файл токенов; шрифт Inter входит в пакет (без загрузки из сети). Новые разрешения не нужны.

- Unavailable products: sold-out or removed products are now marked "Нет в наличии" instead of showing the last price as if it were current.
  Detected per marketplace (Ozon, Wildberries, Yandex Market) from explicit signals only and confirmed on 2 consecutive checks; page-load or parser
  failures become a separate error state. No fake price points are added. The last price is greyed with the date it was last seen; charts draw a
  dashed grey line that stops at the last real price. Automatic filters "Недоступные" and "Ошибки" sit next to the user's folders (products are never
  moved out of folders). Unavailable products are re-checked about daily and return to normal tracking automatically when the price reappears.
- Group chart: quick filter by name or ID, "select/deselect matching", "only matching", "only selected", × to clear. Groups of more than 10 products open
  with the first 8 lines selected; the last selection is remembered per folder. Filtering only redraws the legend (debounced), not the chart.
- Fullscreen button on single-product and group charts (Esc to exit); the chart is redrawn at the screen size and the filter panel stays usable.
  The toolbar popup cannot go fullscreen, so there the button opens the same chart in a browser tab.
- Fix: Ozon availability is no longer guessed from the whole page text (it matched recommendation tiles).
