# Apply on GitHub (about 15 minutes)

1. New repo `dev-kleo/dev-kleo` (public). Add `github-profile/README.md` as its README.md. Fill <<EMAIL>> (or delete it). The `Luffy-me` repo is your old profile README: it is an unfilled template with trophies, quotes and a donate section, and it does not show on your profile because the repo name is not `dev-kleo`. Delete it after copying nothing from it.
2. Profile → Edit profile. Bio: `MSc Economics & International Business · South Ural State University · RAG, browser tools, software` . Remove "On vacation" status. Add real location/email if you want them public.
3. Pins (Customize your pins): ragbot, Uniassist, price-tracker, openhighlights, website (website only with a README and description).
4. Forks gstack, paperclip, ai-engineering-from-scratch: Settings → Danger zone → Delete repository, or make private. Deleting is permanent; forks hold nothing of yours unless you committed to them.
5. InkMind: Settings → rename the repo to `openhighlights` (old links redirect), then update the link in the profile README. Add a description and a README with a screenshot. `website`: add a description, or make private.
6. Publish the extension:
   cd path\to\ozon-price-tracker-2.1.0
   git remote add origin https://github.com/dev-kleo/price-tracker.git
   git push -u origin master
   (create the empty repo `price-tracker` on GitHub first; add a LICENSE of your choice)
7. ragbot: add a "Limitations & evaluation" section (retrieval recall@k on a small question set, known failure cases) and a note that the demo accounts are for local use only.
