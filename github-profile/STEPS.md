# Apply on GitHub (about 15 minutes)

1. New repo `dev-kleo/dev-kleo` (public). Add `github-profile/README.md` as its README.md. Fill the <<...>> fields.
2. Profile → Edit profile. Bio: `<<Degree>> student at <<University>> · RAG, retrieval evaluation, software` . Remove "On vacation" status. Add real location/email if you want them public.
3. Pins (Customize your pins): ragbot, Uniassist, price-tracker, InkMind, website (only if they have a README and description).
4. Forks gstack, paperclip, ai-engineering-from-scratch: Settings → Danger zone → Delete repository, or make private. Deleting is permanent; forks hold nothing of yours unless you committed to them.
5. Luffy-me, website, InkMind: add a description + README, or make private.
6. Publish the extension:
   cd path\to\ozon-price-tracker-2.1.0
   git remote add origin https://github.com/dev-kleo/price-tracker.git
   git push -u origin master
   (create the empty repo `price-tracker` on GitHub first; add a LICENSE of your choice)
7. ragbot: add a "Limitations & evaluation" section (retrieval recall@k on a small question set, known failure cases) and a note that the demo accounts are for local use only.
